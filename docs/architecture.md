# 架构设计

## 目标

第一阶段只建设 `market-data`，把“行情获取、落库、查询、页面展示”做稳定。

原则：

1. 东方财富只在本地 `market-data` 服务中访问。
2. DuckDB 只由 `market-data` 直接读写。
3. Web 页面和 AI 全部通过 REST API 查询。
4. 后续新增 Tushare、券商行情时，不改变上层接口。
5. 数据服务只负责客观行情与指标，不负责自动下单。

## 总体结构

```text
东方财富
   │
   ├─ eastmoney-data-sdk
   └─ 东财公开 HTTP 接口
   │
   ▼
market-data
   │
   ├─ 全市场分页同步
   ├─ 日 K / 分钟 K / 分时
   ├─ 指数 / 行业 / 概念板块
   ├─ 全市场技术指标
   ├─ 定时任务
   └─ market.duckdb
   │
   ▼
stock-select
   │
   ├─ 硬过滤
   ├─ 趋势过滤
   ├─ 形态识别
   ├─ 技术评分
   ├─ Top10 / 重点3只
   ├─ 次日交易计划
   └─ select.duckdb
   │
   ├───────────────┐
   ▼               ▼
Web 管理页          AI 查询接口
```

## 模块

### services/market-data

后端数据服务。

职责：

- 获取全 A 股基础行情。
- 获取单股日 K、分钟 K、分时。
- 保存 DuckDB。
- 工作日收盘后自动增量同步。
- 提供历史日 K 初始化任务。
- 提供指数、行业、概念板块接口。
- 提供 AI 聚合接口。

### services/stock-select

收盘后选股服务。

职责：

- 只通过 market-data API 获取行情，不直接读取 market.duckdb。
- 默认排除北交所、科创板、ST。
- 只做 MA5/MA10/MA20 多头趋势。
- 识别缩量回踩、放量突破、强势后首次回踩、趋势延续。
- 保存 Top10 候选和重点3只。
- 为候选生成次日买入区、止损、止盈、移动止盈和时间止损计划。
- 默认工作日16:40自动执行。
- 选股历史独立保存在 select.duckdb。

### apps/web

本地管理页面。

页面：

- 市场总览
- 股票查询
- 板块对比
- 数据同步

## DuckDB 表

### stock

股票基础信息。

### daily_price

每个交易日的股票行情和基础估值字段：

- 开盘、收盘、最高、最低、昨收
- 成交量、成交额
- 涨跌幅、振幅、换手率、量比
- PE、PB
- 总市值、流通市值

### minute_price

只保存用户查询、候选股或持仓的分钟数据。

不保存 5000 多只股票的全市场每一分钟，避免无意义的数据膨胀。

### sector

行业和概念板块实时排名。

### market_index

上证、深证、创业板、科创50、沪深300。

### sync_job

记录同步任务状态与进度。

## 同步策略

### 每日增量

东财 `clist` 一次可以返回多只股票。

因此收盘后同步全市场时：

```text
约 5000 只股票
   ↓
每页 500 只
   ↓
约 10～12 次请求
   ↓
写入 daily_price
```

不需要逐只请求 5000 次。

### 历史初始化

第一次需要均线和趋势计算时，对每只股票逐个拉取最近 120～250 个交易日日 K。

这是一次性重任务，所以：

- 手动启动。
- 顺序执行。
- 每 20 只更新一次进度。
- 单只失败不终止全任务。

### 分钟数据

只在以下场景获取：

- 用户打开个股页面。
- AI 查询个股。
- 未来候选池监控。
- 当前持仓监控。

## 服务边界

```text
market-data  = 只负责“数据是什么”
stock-select = 只负责“哪些股票符合策略”
Web          = 只负责展示和手工操作
AI           = 读取结构化结果，做解释、比较和二次判断
```

后续即使更换 Tushare、券商行情或增加其他策略，也不需要改变页面与 AI 的调用方式。

## AI 接口

### GET /api/v1/ai/market

一次返回：

- 主要指数
- 上涨/下跌家数
- 涨跌幅超过 3% 的家数
- 总成交额
- 涨幅前十
- 成交额前十
- 行业前十/后十
- 概念前十/后十

### GET /api/v1/ai/stock/:code

一次返回：

- 股票基础信息
- 实时行情
- 最近 120 日日 K
- 最近 1 分钟数据
- 当日分时
- MA5/MA10/MA20
- 5 日/20 日涨幅
- 20 日高点
- 相对 5 日成交量
- 距 MA5 偏离

stock-select 直接消费这些数据。

### GET /api/v1/select/ai

一次返回：

- 当前市场背景
- 最新选股批次
- 重点3只
- Top10候选
- 每只候选的次日执行计划
- 当前固定交易纪律
