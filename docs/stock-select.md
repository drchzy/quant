# 超短趋势选股

## 目标

这套策略解决的是“前一天做计划，第二天按计划执行”。

它不是预测模型，也不会输出“明天一定上涨”的结论。

每天收盘后执行：

```text
全市场约5000只股票
        ↓
硬过滤
        ↓
多头趋势过滤
        ↓
形态识别
        ↓
技术评分
        ↓
Top 10候选
        ↓
重点3只
        ↓
生成次日交易计划
```

## 默认排除

- 北交所
- 科创板
- ST、退市股票

创业板保留。

这些规则都可以通过环境变量修改。

## 第一层：流动性过滤

默认要求：

- 股价不低于3元
- 当日成交额不低于1亿元
- 总市值2亿～1000亿元
- 换手率1%～18%
- 当日涨跌幅-3%～7%

## 第二层：趋势过滤

必须满足：

```text
收盘价 > MA5 > MA10 > MA20
MA5 > 前一日MA5
MA10 >= 前一日MA10
```

也就是只做右侧趋势，不做下降趋势里的“抄底”。

## 第三层：形态

按优先级识别：

### 缩量回踩

- 靠近MA5
- 成交量低于近5日平均量
- 趋势结构保持完整

### 放量突破

- 接近或突破前20日高点
- 当日成交量明显放大
- 收盘靠近日内高位

### 强势后首次回踩

- 前一日涨幅较大
- 当前交易日出现第一次正常回踩
- 仍守住短期趋势

### 趋势延续

不属于前三类，但MA5/MA10/MA20多头结构完整。

## 评分

评分会综合：

- 均线趋势
- 距MA5距离
- 5日涨幅
- 20日涨幅
- 成交量相对近5日均量
- 换手率
- 成交额
- 收盘在日内的位置
- 是否冲高回落
- 当日是否已经涨幅过大

默认最低分：55。

## 次日计划

每只候选都会固定生成：

- 买入区间
- 不追高价格
- 止损价格
- 第一止盈
- 第二止盈
- 移动止盈规则
- 最大单票仓位
- 时间止损

默认纪律：

```text
高于前一日收盘约4%：原则上不追
初始最大亏损：约3%
第一止盈：约+4%
第二止盈：约+6%
浮盈达到+4%：启动移动止盈
从阶段高点回撤2%：保护利润
单票最大仓位：50%
2个交易日没有按预期走强：时间止损
```

价格会同时参考MA5、MA10，所以实际止损不只是固定百分比。

## 接口

### 手动运行

```text
POST /api/v1/select/run
```

### 最新结果

```text
GET /api/v1/select/latest
```

### 历史记录

```text
GET /api/v1/select/runs
GET /api/v1/select/runs/:id
```

### AI聚合接口

```text
GET /api/v1/select/ai
```

一次返回：

- 当前市场背景
- 重点3只
- Top10候选
- 每只候选的交易计划
- 当前止盈止损纪律

## 定时执行

默认：

- 16:10 market-data 同步当天行情
- 16:40 stock-select 自动选股

历史日K第一次必须在“数据同步”页面初始化。


# 策略复盘

每天16:40自动选股前，会先复盘已经有后续行情的历史候选。

复盘记录包括：

- 次日开盘、最高、最低、收盘
- 次日相对选股日收盘涨跌
- 是否进入计划买入区
- 实际近似成交价
- 最大浮盈、最大浮亏
- 是否触发第一/第二止盈
- 最终退出价格
- 退出原因
- 实际收益

## 日K回放原则

当前复盘基于日K，因此是近似结果。

为了避免过度乐观：

1. 同一根日K同时触发止损和止盈时，按止损优先。
2. 当天新触发的移动止盈，从下一交易日开始生效。
3. 次日没有进入计划买入区，则记为“未成交”，不强行计算收益。

未来如果接入完整历史1分钟数据，可以升级为分钟级精确回放。

## 复盘接口

```text
POST /api/v1/select/review/run
GET  /api/v1/select/review/summary
GET  /api/v1/select/review/latest
```

# 参数回测

参数回测会重新使用历史交易日当时已经存在的数据生成候选，不使用未来数据选股。

默认回测：

- 最近60个交易日
- 每日重点前3只
- 比较432组退出参数

比较范围：

- 止损：2% / 2.5% / 3% / 3.5%
- 目标：4% / 5% / 6% / 8%
- 移动止盈启动：3% / 4% / 5%
- 高点回撤：1.5% / 2% / 2.5%
- 最长持有：1 / 2 / 3个交易日

统计指标：

- 成交样本数
- 胜率
- 平均收益
- 盈亏比
- 最大回撤
- 复合总收益
- 综合分

综合分只用于同一批历史样本内比较参数，不代表未来收益。

回测得到的“最优参数”只作为建议展示，系统不会自动覆盖当前交易参数，避免样本过拟合后直接影响实盘。

## 回测接口

```text
POST /api/v1/select/backtest
GET  /api/v1/select/backtests
GET  /api/v1/select/backtests/latest
GET  /api/v1/select/backtests/:id
```
