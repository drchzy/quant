# 超短趋势选股

## 目标

这套策略解决的是“前一天做计划，第二天按计划执行”。

它不是预测模型，也不会输出“明天一定上涨”的结论。

每天收盘后执行：

```text
全市场约5000只股票
        ↓
硬过滤
        ↓
多头趋势过滤
        ↓
形态识别
        ↓
技术评分
        ↓
Top 10候选
        ↓
重点3只
        ↓
生成次日交易计划
```

## 默认排除

- 北交所
- 科创板
- ST、退市股票

创业板保留。

这些规则都可以通过环境变量修改。

## 第一层：流动性过滤

默认要求：

- 股价不低于3元
- 当日成交额不低于1亿元
- 总市值2亿～1000亿元
- 换手率1%～18%
- 当日涨跌幅-3%～7%

## 第二层：趋势过滤

必须满足：

```text
收盘价 > MA5 > MA10 > MA20
MA5 > 前一日MA5
MA10 >= 前一日MA10
```

也就是只做右侧趋势，不做下降趋势里的“抄底”。

## 第三层：形态

按优先级识别：

### 缩量回踩

- 靠近MA5
- 成交量低于近5日平均量
- 趋势结构保持完整

### 放量突破

- 接近或突破前20日高点
- 当日成交量明显放大
- 收盘靠近日内高位

### 强势后首次回踩

- 前一日涨幅较大
- 当前交易日出现第一次正常回踩
- 仍守住短期趋势

### 趋势延续

不属于前三类，但MA5/MA10/MA20多头结构完整。

## 评分

评分会综合：

- 均线趋势
- 距MA5距离
- 5日涨幅
- 20日涨幅
- 成交量相对近5日均量
- 换手率
- 成交额
- 收盘在日内的位置
- 是否冲高回落
- 当日是否已经涨幅过大

默认最低分：55。

## 次日计划

每只候选都会固定生成：

- 买入区间
- 不追高价格
- 止损价格
- 第一止盈
- 第二止盈
- 移动止盈规则
- 最大单票仓位
- 时间止损

默认纪律：

```text
高于前一日收盘约4%：原则上不追
初始最大亏损：约3%
第一止盈：约+4%
第二止盈：约+6%
浮盈达到+4%：启动移动止盈
从阶段高点回撤2%：保护利润
单票最大仓位：50%
2个交易日没有按预期走强：时间止损
```

价格会同时参考MA5、MA10，所以实际止损不只是固定百分比。

## 接口

### 手动运行

```text
POST /api/v1/select/run
```

### 最新结果

```text
GET /api/v1/select/latest
```

### 历史记录

```text
GET /api/v1/select/runs
GET /api/v1/select/runs/:id
```

### AI聚合接口

```text
GET /api/v1/select/ai
```

一次返回：

- 当前市场背景
- 重点3只
- Top10候选
- 每只候选的交易计划
- 当前止盈止损纪律

## 定时执行

默认：

- 16:10 market-data 同步当天行情
- 16:40 stock-select 自动选股

历史日K第一次必须在“数据同步”页面初始化。
